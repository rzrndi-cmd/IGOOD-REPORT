Pembersihan & Reset Data (Danger Zone)

Akses Terbatas: Super Admin Only

Halaman ini berisi semua alat pembersih database lokal dan server Supabase. Tindakan di bawah ini bersifat merusak dan tidak dapat dibatalkan. Gunakan hanya saat migrasi sistem atau pembersihan data uji coba.

Reset Stok HP / iPad

Menghapus seluruh daftar inventaris unit HP/iPad baik di perangkat lokal ini maupun di server.

⚠️ Konsekuensi: Semua data stok HP/iPad terhapus permanen.

Reset Stok Aksesoris

Menghapus seluruh daftar inventaris aksesoris baik di perangkat lokal ini maupun di server.

⚠️ Konsekuensi: Semua data stok aksesoris terhapus permanen.

Reset Katalog Jasa Service

Menghapus seluruh daftar katalog jasa service (jenis layanan dan tarif) di perangkat lokal dan server.

⚠️ Konsekuensi: Kasir tidak dapat memilih layanan cepat, katalog harus diinput ulang.

Reset Katalog Lain-lain

Menghapus seluruh daftar katalog barang lain-lain di perangkat lokal dan server.

⚠️ Konsekuensi: Daftar item bebas/lain-lain terhapus permanen.

Reset Antrean Nota Service

Menghapus semua antrean nota service masuk/keluar/cancel baik secara lokal maupun di server database.

⚠️ Konsekuensi: Semua riwayat servisan pelanggan hilang permanen.

Reset Request Preorder

Menghapus seluruh antrean pesanan preorder beserta catatan DP/uang muka lokal dan server.

⚠️ Konsekuensi: Kehilangan data antrean preorder konsumen secara permanen.

Reset Beban Operasional

Menghapus seluruh pengeluaran/beban operasional bulanan toko baik secara lokal maupun di server.

⚠️ Konsekuensi: Seluruh data beban/biaya bulanan terhapus. Laba bersih akan dikalkulasi ulang.

Reset Riwayat Laporan Transaksi

Menghapus riwayat transaksi penjualan kasir lokal secara total.

⚠️ Konsekuensi: Riwayat transaksi terhapus. Stok unit HP/iPad & kuantitas aksesoris yang pernah terjual otomatis dikembalikan ke inventaris.

Master System Reset (Tindakan Kritis)

Hapus Seluruh Data Server

Menghapus seluruh tabel data pada server database Supabase secara permanen (Stok HP, Aksesoris, Jasa, Transaksi, Preorder, Service, dll).

⚠️ Konsekuensi: Server database Supabase akan kosong bersih. Data lokal perangkat ini tetap ada.
