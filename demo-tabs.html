Showcase Komponen Tab

Koleksi desain tab interaktif premium, taktis, dan responsif menggunakan token Igood.

1. Segmented Control / Capsule Tab

Cocok untuk pilihan filter bertipe biner atau opsi grup kecil (2-4 item). Sangat hemat tempat dan taktil.

Detail Shift Pagi

Jam Kerja: 08:00 - 16:00 WIB. Laporan harian diisi oleh kasir shift pagi sebelum serah terima.

Detail Shift Malam

Jam Kerja: 16:00 - 22:00 WIB. Mengharuskan tutup buku harian dan penarikan data ke printer Bluetooth.

Gabungan Semua Shift

Menampilkan komparasi performa pendapatan toko antara shift pagi dan shift malam.

2. Sliding Underline Tab

Layout tab modern standar industri. Garis penunjuk bergeser secara mulus sesuai tab yang dipilih.

Ringkasan Keuangan

Total penjualan hari ini meningkat sebesar 12.5% dibanding kemarin. Total unit iPhone terjual: 5 unit.

Detail Transaksi Terkini

Daftar transaksi kasir terperinci dari penjualan aksesoris, unit Android, service, dan tukar tambah.

Grafik Analisis Pendapatan

Visualisasi tren pendapatan mingguan menggunakan diagram garis. Cocok untuk tinjauan owner.

3. Premium Icon Grid Tab (Tile Selector)

Desain layout tab kasir yang saat ini digunakan di halaman Input Penjualan Igood. Ukuran tombol minimum 44x44px untuk target sentuh optimal di perangkat mobile.

Kategori: iPhone

Pilih tipe iPhone (11, 12, 13, 14, 15 Pro Max) beserta nomor IMEI, warna, kondisi, dan status garansi.

Kategori: Android

Input merek Android (Samsung, Oppo, Vivo, Xiaomi), kapasitas RAM/Internal, IMEI, dan harga jual bersih.

Kategori: Aksesoris

Pilih produk (charger, case, tempered glass, headset) dengan pencarian cepat nama item.

Kategori: Tukar Tambah

Input detail unit HP lama milik kustomer beserta HP baru yang dibeli dan selisih pembayaran.

4. Vertical Sidebar Tab

Sangat ideal untuk antarmuka Admin Center, Pengaturan, atau tampilan Desktop/Tablet.

Pengaturan Profil Toko

Kelola nama toko, alamat cabang, kontak WhatsApp kustomer, dan logo yang akan dicetak pada struk kasir.

Terakhir diperbarui: 26 Juni 2026

Integrasi & Sinkronisasi Supabase

Sambungkan database lokal SQLite dengan server cloud Supabase secara real-time. Dilengkapi fitur backup offline.

Status Koneksi: Terhubung

Konfigurasi Printer Kasir

Cari dan hubungkan printer Bluetooth Thermal (ukuran kertas 58mm atau 80mm) untuk cetak struk nota langsung.

Perangkat Terhubung: RPP02N (58mm)
